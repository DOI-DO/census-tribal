## Welcome to the Department of the Interior's <br> _User's Guide for Census-Tribal Data._ 

</div>
  
This repository was created to support DOI and other federal employees who want to access and analyze Census data for American Indian and Alaska Native (AIAN) geographies.

The repository was created in January 2026 and is maintained by Ann Miller and Emily Silverman from the Office of Policy Analysis. It includes code to pull data from the Census API and to combine and manipulate AIAN tables. We also provide a set of reference data tables for Tribal geographies and Federally recognized Tribal entities, including a table that crosswalks Census geographies with the list of Federally recognized tribes and native villages. See the data folder and associated README for more information.
