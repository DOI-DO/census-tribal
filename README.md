# census-tribal

## Welcome to the Census Tribal data user's guide for the Department of the Interior

This repository was created to support DOI and other federal users of Census data to access and analyze Census data for AIAN geographies.

The repository was created and is maintained by Ann Miller and Emily Silverman from the Office of Policy Analysis in January 2026. It includes code to pull data from the Census API and to combine and manipulate AIAN tables. We also provide a set of reference data tables for Tribal geographies and tribal entities. See the data folder and associated README for more information.
